# Sara Vadell — Portfolio

Product designer and product manager based in Amsterdam.

A single-page static site: `index.html` plus the `images/` and `videos/` folders. No build step.

## Run locally
Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploy
Hosted on Vercel, imported from this repository. Every push to `main` redeploys automatically.
